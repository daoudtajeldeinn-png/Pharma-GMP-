# IPQC Module 2.2: IPQC Tests for Tablets

## Overview

Specific In-Process Quality Control tests are performed during tablet manufacturing to ensure product quality and compliance.

## Physical Tests

- Weight variation test
- Hardness test
- Thickness measurement
- Diameter measurement
- Friability test
- Disintegration test

## Chemical Tests

- Assay of active ingredient
- Content uniformity
- Dissolution testing
- Impurity profiling
- Moisture content

## Process Tests

- Granule flow properties
- Bulk density
- Tapped density
- Angle of repose
- Compressibility index

## Equipment Verification

- Tablet press performance
- Die and punch condition
- Compression force monitoring
- Feeder system check
- Dust extraction system

## Acceptance Criteria

- Pharmacopoeial standards
- In-house specifications
- Process validation data
- Regulatory requirements
