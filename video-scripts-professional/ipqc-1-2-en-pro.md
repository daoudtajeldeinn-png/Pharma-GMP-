# IPQC Module 1.2: Difference Between IPQC and QC

## Overview

Understanding the distinction between In-Process Quality Control (IPQC) and Quality Control (QC) is essential for effective pharmaceutical manufacturing.

## Key Differences

- IPQC occurs during manufacturing process
- QC is performed on finished products
- IPQC is real-time monitoring
- QC is batch release testing
- IPQC prevents defects
- QC detects defects

## IPQC Focus

- In-process testing
- Process parameter monitoring
- Equipment verification
- Environmental controls
- Personnel performance

## QC Focus

- Final product testing
- Batch release decisions
- Stability testing
- Microbiological testing
- Chemical analysis

## Integration

- Both systems work together
- IPQC data informs QC decisions
- QC results validate IPQC methods
- Combined approach ensures quality
