# IPQC Module 4.2: IPQC Tests for Liquids

## Overview

Specific In-Process Quality Control tests are essential during liquid manufacturing to ensure product quality and compliance.

## Physical Tests

- Volume accuracy test
- pH measurement
- Viscosity test
- Specific gravity test
- Clarity and color test
- Particulate matter test

## Chemical Tests

- Assay of active ingredient
- Related substances
- Impurity profiling
- Preservative content
- Antioxidant content
- Buffer capacity

## Microbiological Tests

- Sterility test (if required)
- Bioburden test
- Endotoxin test
- Preservative efficacy test
- Microbial limits test

## Process Tests

- Filtration integrity test
- Mixing uniformity
- Temperature monitoring
- Fill weight accuracy
- Seal integrity test

## Equipment Verification

- Mixing vessel performance
- Filling machine accuracy
- Filtration system integrity
- Temperature control system
- pH meter calibration
