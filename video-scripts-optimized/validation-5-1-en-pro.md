## Overview

Change Control is essential to ensure that any change in the system or process is done in an organized and controlled manner.

What is Change Control?

Change Control is a system for managing all changes in systems and processes.

An organized system for managing changes

- Ensures changes are safe and effective
- Prevents unauthorized changes Provides a record for traceability of Change Control in Validation:
- Ensures continuity of validation state
- Prevents changes that affect quality
- Ensures regulatory compliance Provides a record for traceability Any change may affect validation state Changes must be evaluated before implementation Changes may require revalidation Types of Changes  There are several types of changes, each requiring a different level of review.
- **Minor Changes**: Small changes that do not affect quality Do not require revalidation Require simple review Example: Changing supplier for non-critical materials Major Changes: Large changes that may affect quality May require revalidation Require comprehensive review Example: Changing main process Emergency Changes: Immediate changes due to emergencies Require immediate implementation Require subsequent review Example: Replacing broken equipment Temporary Changes: Temporary changes for a specific period Require review before and after Require requalification Example: Using alternative equipment temporarily Change Control Procedures  Change Control includes several organized steps.
- **Steps**: Change Request: Submit change request form Explain reason for change Describe proposed change Identify expected benefits Change Evaluation: Evaluate impact on validation Evaluate impact on quality Evaluate impact on compliance Evaluate impact on processes Change Approval: Approval from quality Approval from management Approval from experts Approval from regulatory authorities when necessary Change Implementation: Implement change according to plan Monitor implementation Record all activities Address any problems Effectiveness Verification: Verify that change is effective Verify no negative effects Verify compliance Document Revalidation if Required: Determine if revalidation is required Execute revalidation Analyze results Document Change Control Examples  Let's look at some practical examples of Change Control.
