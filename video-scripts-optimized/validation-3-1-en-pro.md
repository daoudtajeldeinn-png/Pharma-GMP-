# Validation - Unit 1 IQ (Installation Qualification)  In this lecture, we will discuss IQ or Installation Qualification.

> **Pharmaceutical Quality & Compliance Training Script**

## Overview

IQ is the first stage of validation and is essential to ensure correct equipment installation.

What is IQ?

IQ is the verification of equipment installation.

Installation qualification Ensure installation follows specifications Ensure installation meets requirements Ensure installation is safe of IQ:

- Ensures correct installation
- Reduces future problems
- Ensures employee safety
- Essential for subsequent validation stages IQ must be performed immediately after installation IQ must be fully documented IQ is essential before OQ and PQ IQ Contents  IQ includes several elements that must be verified.
- **Main Elements**: Site Verification: Ensure site is appropriate Ensure site meets requirements Ensure site is safe Ensure site facilitates maintenance Facilities Verification: Verify electricity availability Verify water availability Verify steam availability Verify compressed gas availability Equipment Verification: Verify equipment matches specifications Verify equipment is intact Verify equipment is complete Verify equipment operates Installation Verification: Verify correct installation Verify connections Verify mounting Verify ventilation Documentation Verification: Verify document availability Verify document completeness Verify document accuracy Verify document approval IQ Procedures  Executing IQ requires following specific procedures.
- **Steps**: Review Specifications: Review technical specifications Review drawings Review installation guidelines Review safety requirements Site Inspection: Inspect designated site Inspect available facilities Inspect surrounding environment Inspect accessibility Equipment Inspection: Inspect equipment upon receipt Inspect equipment for integrity Inspect equipment for completeness Inspect equipment for compliance Installation Monitoring: Monitor installation process Ensure installation guidelines are followed Ensure work quality Address any problems Installation Testing: Test electrical connections Test mechanical connections Test safety systems Test basic functions Documentation: Document all activities Prepare IQ report Review report Approve report IQ Example  Let's look at a practical example of IQ.
