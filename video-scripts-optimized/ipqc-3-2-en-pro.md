# IPQC Module 3.2: IPQC Tests for Capsules

## Overview

Specific In-Process Quality Control tests are essential during capsule manufacturing to ensure product quality and compliance.

## Physical Tests

- Weight variation test
- Content uniformity test
- Disintegration test
- Dissolution test
- Moisture content test
- Shell integrity test

## Chemical Tests

- Assay of active ingredient
- Related substances
- Impurity profiling
- pH of solution
- Residual solvents

## Process Tests

- Powder flow properties
- Bulk density
- Tapped density
- Fill weight accuracy
- Shell thickness
- Seal integrity

## Equipment Verification

- Capsule filling machine
- Powder feed system
- Weight check system
- Sealing equipment
- Polishing machine
- Inspection system

## Acceptance Criteria

- Pharmacopoeial standards
- In-house specifications
- Process validation data
- Regulatory requirements
