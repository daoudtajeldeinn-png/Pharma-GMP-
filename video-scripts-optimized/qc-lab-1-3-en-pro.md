## Overview

Analytical methods are essential for inspecting and testing materials and products.

Types of Analytical Methods  There are several types of analytical methods used in the laboratory.

- **Physical Methods**: Test physical properties Test appearance Test color Test odor Test taste Chemical Methods: Test chemical composition Test purity Test concentration Test reactions Microbiological Methods: Test bacteria Test fungi Test yeasts Test contamination Spectroscopic Methods: UV-Vis IR NMR MS Chromatographic Methods: HPLC GC TLC Electrophoresis Developing Analytical Methods  Developing analytical methods is essential to ensure result accuracy.
