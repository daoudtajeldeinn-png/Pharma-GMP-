## Overview

Root cause analysis is essential to effectively solve problems and prevent their recurrence.

What is Root Cause?

The root cause is the fundamental cause of the problem, not just the apparent cause.

The fundamental cause of the problem The cause that, if removed, will prevent problem recurrence The cause that lies at the base of the cause chain The cause that requires deep analysis of Root Cause Analysis:

- Ensures permanent problem solution
- Prevents problem recurrence
- Reduces costs
- Improves quality Root cause is not always clear Root cause requires deep analysis Root cause requires analysis tools Root cause must be documented Root Cause Analysis Tools  There are several tools that can be used for root cause analysis.
- **Main Tools**: 5 Whys: Ask "why" 5 times Determine root cause Simple and fast Effective for simple problems Example: Why did the problem occur?
Why did the cause occur?

Why did the second cause occur?

And so on until reaching the root cause Fishbone Diagram (Ishikawa): Visualize all possible causes Categorize causes into categories Effective for complex problems Provides comprehensive view Main Categories: Materials Machines Manpower Methods Environment Measurement Pareto Analysis: Identify most common causes Focus on main causes Effective for recurring problems Helps determine priorities Fault Tree Analysis: Fault tree analysis Determine root causes Effective for technical problems Provides logical analysis Applying 5 Whys  Let's see how to apply the 5 Whys method in practice.

- **Practical Example**: Problem: Product quality failure Question 1: Why did the product fail quality test?
- **Answer**: Because concentration was low.
- **Question 2**: Why was concentration low?
- **Answer**: Because raw materials were low quality.
- **Question 3**: Why were raw materials low quality?
- **Answer**: Because the new supplier was not tested properly.
- **Question 4**: Why was the new supplier not tested properly?
- **Answer**: Because supplier verification procedures were not followed.
- **Question 5**: Why were supplier verification procedures not followed?
- **Answer**: Because the responsible employee was not trained adequately.
- **Root Cause**: Lack of employee training on supplier verification procedures.
